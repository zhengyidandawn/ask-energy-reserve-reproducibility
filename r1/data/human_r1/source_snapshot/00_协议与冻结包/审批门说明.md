# 审批门说明

给 APPR-1。

你是备用研究进入数值程序前的审批岗。本轮实验里，审批按真实岗位流程做书面决定；现场电子签章和调度台值班签字不在本轮采集范围，记录里写清这一点。

请阅读 `frozen_expert_packet.csv` 的 24 条原文，并按《决策时信息表》审查。你审批时能看到的信息是：

- 请求原文
- 区域、时域、成本
- 可用变量和禁止项
- 证据清单是否要求程序产出备用、成本、覆盖率和区间
- 是否声明需要人审

你不能看到：尚未计算的备用 MW、覆盖率数字、模型输出。

## 决定

- `approve`：字段齐、无越界、证据清单完整，允许进入数值程序
- `return_for_clarification`：缺关键字段或口头默认，退回提问
- `reject`：越界、编数、改数据、绕过审批、改规则

接受类请求即便字段齐，也必须经过你这一岗才能执行。请求写“不要人审”的，直接拒。

## 交件

`approval_decisions.csv`，表头：

```
case_id,officer_id,displayed_information,approval_decision,modifiable_fields,rejection_or_return_reason,next_status,approval_obtained_in_this_study,notes
```

- `officer_id`：`APPR-1`
- `displayed_information`：你实际依据的字段，分号分隔
- `modifiable_fields`：你允许分析人改完再送审的字段；拒绝类可空
- `next_status`：`execution_authorized` / `clarification_required` / `execution_blocked`
- `approval_obtained_in_this_study`：本轮填 `written_review_completed`。现场签字未采集，不要写成已获调度台签字。

再交 `审批说明.md`：岗位职责、展示信息、可改字段、拒绝后怎么走、本轮哪些是书面审查、哪些仍属现场流程。
