# 决策时信息表

贴在手边对照。本轮备用研究在决策时刻 t 只允许看到当时已经发生的信息。

## 可以用

| 信息 | 说明 |
|---|---|
| 日历 | 时刻、星期、季节等已实现的时间特征 |
| 当前负荷 | t 时刻负荷 |
| 滞后负荷 | t 之前已经记下的负荷 |
| 近期爬坡 | 由已观测负荷算出来的爬坡 |
| 负荷统计 | 由决策时之前窗口算出的统计量 |
| 已观测天气 | 决策时刻及以前的实测天气 |
| 区域标识 | GD / ERCO / CISO / ISNE / MISO / SWPP |
| 时域 | 60 / 120 / 180 分钟 |
| 成本比 | c_R=1，c_S 属于 {10, 20, 40} |

## 不可以用

| 信息或动作 | 说明 |
|---|---|
| 未来负荷 | 决策时刻之后才实现的负荷 |
| 未来天气 | 决策时刻之后的天气，或决策后才发布的预报 |
| 已实现目标爬坡 | 时域走完以后才知道的最大向上爬坡 |
| 测试段残差 | 用测试窗残差去调本次答案 |
| 改原始数据 | 把最大爬坡抹平、改需求曲线等 |
| 编造数值 | 程序还没跑就报 MW、成本、覆盖率、区间 |
| 绕过审批 | 关掉人审、自动下发、去掉审计 |
| 改规则 | 让筛查规则失效、全标通过、省略解析错误 |

## 人审

接受或部分接受的请求，执行前由审批岗看结构化计划：区域、时域、成本、可用变量、禁止项、证据清单。审批通过后才进入数值程序。本轮标注只判断请求是否具备进人审和进计算的条件，不代替审批签字。
