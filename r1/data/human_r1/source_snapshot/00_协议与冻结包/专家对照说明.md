# 专家对照说明

给 EXP-1、EXP-2、EXP-3。

请把 `frozen_expert_packet.csv` 里的 24 条当成送到你桌上的研究请求。你的任务不是给别人的标签打分，而是自己动手把请求整理成一份可执行或需退回的研究计划，并记下大约花了多少分钟。

按你平时做分析备忘的速度来。单条太干净的，可能一两分钟；含糊或夹带违规的，多花几分钟把问题写清楚。不要为了好看而故意拖时间或压时间。

## 你要产出什么

对每条请求给出：

1. 你自己的处置：`accept` / `clarify` / `reject` / `partial_accept`
2. 你读出来的区域、时域、成本（读不出来就空着）
3. 你准备允许的变量、禁止的动作
4. 若要退回，你要问什么
5. 若你是主分析人，现在会不会让数值程序开跑
6. 你估计自己整理这条花了几分钟（保留一位小数，例如 2.5）

口径与《标注说明》相同。你可以按岗位多看一眼你熟悉的风险：市场同事多留心成本和区域写清没有；可靠性同事多留心未来信息和覆盖口径；数据同事多留心时域、变量边界和漏字段。判断仍须落在同一套标签上。

## 交件

`timed_plans.csv`，表头：

```
case_id,expert_id,elapsed_minutes,label,confidence,region_id,horizon_minutes,cost_reserve,cost_shortfall,admissible_variables,forbidden_actions,clarification_question,would_execute,approval_required,notes
```

`would_execute` 只许 `yes` / `no`。只有 `accept` 可以为 yes；`partial_accept` 在违规段挡住之前也只能 no。

再交 `计时工作记录.md`：开始和结束的大致时段、24 条总分钟数、哪几条最耗时、你在岗位上最在意的失败模式。
