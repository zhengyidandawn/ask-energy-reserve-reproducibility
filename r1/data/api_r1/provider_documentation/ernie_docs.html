更新时间：2026-09-29
POST
https://qianfan.baidubce.com/v2/chat/completions
调试

调用本接口，发起一次对话请求。

支持模型列表

支持模型列表请查看千帆-模型列表-文本生成。

权限说明

调用本文API，需使用API Key鉴权方式。使用API Key鉴权调用API流程，具体调用流程，请查看认证鉴权。
